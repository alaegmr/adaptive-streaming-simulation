🎥 **Adaptive Bitrate Streaming Project**

A **Flask-based video streaming project** that simulates the core concept of **Adaptive Bitrate Streaming (ABS)**. The system uploads a video, automatically segments it into short **12-second chunks**, and generates multiple resolutions (**360p, 480p, 720p, and 1080p**) using **FFmpeg**. A web-based video player loads the generated playlist and plays the video segment by segment, allowing the user to switch between available resolutions during playback.

The project was developed as a practical implementation to understand the fundamental principles behind **video streaming, video segmentation, buffering, HTTP range requests, and adaptive quality switching**.

#### Technologies Used

* Python
* Flask
* FFmpeg / FFprobe
* HTML / CSS / JavaScript
* Video Streaming
* Adaptive Bitrate Streaming
* JSON
* HTTP Range Requests
